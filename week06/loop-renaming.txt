## Renaming files with loops

Sometimes, you need to rename many files in a systematic/repetitive way.
This is relatively common with omics data files,
as you will often have separate files for each sample,
and you may have many dozens of samples.

Manually renaming these one-by-one is tedious as well as extremely error-prone
and not-reproducible,
while doing this with code is a good example of a general task that you
can apply your coding skills to.
For example, maybe you have a few thousand photos that you want to rename in
a systematic way?

There are many different ways to rename many files in a programmatic way in the shell &ndash;
admittedly none as easy as one might have hoped.
Here, we'll use the `basename` command and a `for` loop.
`for` loops are a verbose method for tasks like renaming,
but are relatively intuitive and good to get practice with because you will use
them in other contexts throughout the course.

#### Creating a set of dummy files to work with

We will start with creating some dummy files that represent alignments
(the results of aligning reads in FASTQ files to a reference genome).
These are stored in `.sam` or `.bam` files.

To create many files at once, we will use a trick called "brace expansion"
(because this is not a commonly used technique, I will only explain it in the
optional bonus reading at the bottom of the page):

```bash
cd /fs/ess/PAS2880/users/$USER/week03
```

```bash
touch results/alignments/sample{01..50}.sam
```

Let's check the names of the files we created and how many there are:

```bash
ls results/alignments
```
```bash-out
results/alignments/sample01.sam
results/alignments/sample02.sam
results/alignments/sample03.sam
results/alignments/sample04.sam
results/alignments/sample05.sam
results/alignments/sample06.sam
# [...output truncated...]
```
```bash
ls results/alignments/ | wc -l
```
```bash-out
50
```

Now, let's say that we noticed these files somehow have the wrong extension:
they are saved as `.sam` (SAM files) but are really `.bam` (BAM files).
We'll have to rename them before moving on the next step in our analysis,
but it would be tedious (and error-prone! and not-reproducible!) to do this by hand.
We will therefore use a loop.

<hr style="height:1pt; visibility:hidden;" />

#### Renaming a single file using variables

To go step-by-step, I will start by showing how we could rename a single
file in the way that we would have to do this in a loop --- using variables.

We will actually make a _separate copy_ of the files in a separate directory,
just to be safe.

To start with, the original file name will be contained in a variable...

```bash
oldname=results/alignments/sample01.sam
```

...and we can also save the new name in a variable:

```bash
newname=results/alignments_bam/$(basename "$oldname" .sam).bam
```
  
Before actually renaming,
note the following trick with `echo` to just print the command instead of executing it ---
that can be a really useful way to check what you're doing is correct when you're
about to run a command you may be nervous about with variables:

```bash
echo mv -v "$oldname" "$newname"
```
```bash-out
mv -v results/alignments/sample01.sam results/alignments_bam/sample01.bam
```

Looks good? Then we remove `echo` and rename the file
(we're using the `-v` to make `mv` report what it's doing):

```bash
mv -v "$oldname" "$newname"
```
```bash-out
results/alignments/sample01.sam -> results/alignments_bam/sample01.bam
```

<hr style="height:1pt; visibility:hidden;" />

#### Looping over all files

Here's how we can loop over these files, saving each file name (one at a time)
in the variable `$oldname`:

```bash
for oldname in results/alignments/*.sam; do
    # ...
done
```

Next, we assign a new name for each file:
  
```sh
for oldname in results/alignments/*.sam; do
    newname=results/alignments_bam/$(basename "$oldname" .sam).bam
done
```

We build and check the renaming command:

```sh
for oldname in *.fastq; do
    newname=results/alignments_bam/$(basename "$oldname" .sam).bam
    echo cp -v "$oldname" "$newname"
done
```
```bash-out
cp -v results/alignments/sample01.sam results/alignments_bam/sample01.bam
cp -v results/alignments/sample02.sam results/alignments_bam/sample02.bam
cp -v results/alignments/sample03.sam results/alignments_bam/sample03.bam
cp -v results/alignments/sample04.sam results/alignments_bam/sample04.bam
# [...output truncated...]
```

Finally, we actually copy and rename by removing `echo`:

```bash
for oldname in *.fastq; do
    newname=results/alignments_bam/$(basename "$oldname" .sam).bam
    cp -v "$oldname" "$newname"
done
```
```bash-out
‘results/alignments/sample01.sam’ -> ‘results/alignments_bam/sample01.bam’
‘results/alignments/sample02.sam’ -> ‘results/alignments_bam/sample02.bam’
‘results/alignments/sample03.sam’ -> ‘results/alignments_bam/sample03.bam’
‘results/alignments/sample04.sam’ -> ‘results/alignments_bam/sample04.bam’
# [...output truncated...]
```
