Setting up

  1. At https://ondemand.osc.edu, start a new RStudio session Starting an RStudio Server session at OSC.
  2. Create a dir week11/exercises using function dir.create("exercise") and navigate there – this should be your working dir for this exercise. 3.Open a new R script in RStudio: File -> New File -> R Script and save the R script as w11_exercises.R in your working dir.
  3. You will write your answers to the exercises below in this R script.

Exercise 1: Create variables and perfrom Airthmatic operation

  1. Assign value 5 to the variable week11, and 10 to variable week12.

  2. Add the values of week11 and week12 and assign the result to to new variable total_weeks. Similarly, multiply the values of week11 and week12 and assign the result to new variable multiply.

Exercise 2: Create vectors and name its elements

  1. Create a vector v1 that contains the numbers 1 to 5 and extract third element. Likewise, create another variable v2 with numbers 6 to 10. Check the structure of v1 and v2.

  2. Change the name of the third element of v1 to “Midweek” and print v1. Check the structure of v1 after changing third element to Midweek. Try to change the v1 to numeric and see what happens.

Note: After replacing a numeric element with a string, the entire vector becomes a character vector. And when you try to convert it back to numeric, R will return NA for the non-numeric elements.

  1. Create a vector v3 that combines v1 and v2. Extract the third, fourth and fifth element of v3 and assign it to v4

Exercise 3: Install and load new packages in R

  1. Install the package palmerpenguins and load the package in R. We will use this package in week13 for data visualization.

Exercise 4: Working with daatframes

  1. Look for help for data.frame function and create a data frame called df1 using vectors v1 and v2 created in exercise 2.

    Last week we worked with the iris data sets which is present in the base R. For this
    exercise, we will use mtcars data sets which is also available in base R.

  2. Save the mtcars data set as a new object called my_cars.

  3. Check the structure of the my_cars data frame. Structure of data shows the datatypes of different variables in the data frame. Compute the mean of the mpg variable of my_cars data frame.

  4. Show the first 6 rows of the my_cars data frame. Select columns mpg, cyl, and hp from the my_cars data frame and display the first 6 rows.

Note: You need to load tidyverse package to use the select function.

  1. Select two columnsmpg and cylinder (cyl) of my_cars data frame with mpg greater than 10 and cyl equal to 6. Change the cyl variable/column name to cylinders. Assign the object to a new_dataframe.

  2. Save the new_dataframe as a csv file called my_cars_filtered.csv in your working directory.
